Before you run make, make sure you have these packeges installed or it won't work:

1. qemu-system-x86_64
2. xorriso 
3. gcc and ld

Feel free and have fun tinkering with my LunarOS!

To run QEMU, just run: make run 

To make the ISO, just run: make LunarOS.iso

To start GDB Debugger, just run: make debug
